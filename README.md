# Mohit Kirtane — Portfolio

Personal portfolio site. React + Vite + Tailwind CSS, no backend.

## Running locally

```bash
npm install
npm run dev
```

## Building

```bash
npm run build
```

Outputs static files to `dist/` — deployable to any static host (Vercel, Netlify,
GitHub Pages, Cloudflare Pages).

## Structure

- `src/components/` — page sections (`Hero`, `Projects`, `Experience`, `Skills`,
  `Education`, `Footer`) plus a shared `Header` and the signature `TraceDiagram`
  hero visual.
- `public/Mohit-Kirtane-Resume.pdf` — served at `/Mohit-Kirtane-Resume.pdf` for the
  résumé download links.
